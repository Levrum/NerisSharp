Currently not accepting contributions from the general public. If you are interested in contribution, please [contact me](mailto:david.sahni@levrum.com) at david.sahni@levrum.com 

If you encounter issues, have suggestions, or would like to request more features please feel free to create an issue. 

Some guidelines for creating issues:
- Please search for existing issues that cover your topic before creating a new one. Duplicate issues will be deleted.
- Do not create issues pertaining to the actual NERIS API and its operation. If there is an issue with how this library interacts with it that is fine, but I have no control over the actual NERIS API itself. 
- Please treat all users and participants with respect. Harassment and discriminative behavior will not tolerated.
